🚀 HOW TO RUN AND SEE THIS LIVE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. BACKEND (Flask Server)
   ────────────────────────
   $ cd campus-connect-mobile
   $ python app.py
   
   Access at: http://localhost:5000

2. MOBILE APP (Flutter)
   ─────────────────────
   $ cd mobile_app
   $ flutter pub get
   $ flutter run -d chrome
   
   Or use quick start:
   $ ./run_app.sh  (Linux/Mac)
   $ run_app.bat   (Windows)

📊 WHAT HAPPENS WHEN YOU CLICK BUTTONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[Register Now] → Sends API request → Shows confirmation → Generates QR ticket
[Scan QR Code] → Opens camera → Scans code → Marks attendance → Shows success
[Approve] → Updates database → Sends to next approval level → Notifies organizer
[View Details] → Fetches event data → Shows full information → Allows actions
[Download Certificate] → Generates PDF → Downloads to device → Can share
[Submit Feedback] → Sends rating & comments → Updates event stats → Thanks user

STUDENT REGISTERS FOR EVENT:
1. Opens app → Auto-login with stored token
2. Sees dashboard with upcoming events
3. Clicks "Tech Workshop 2026"
4. Views full event details
5. Clicks "Register Now"
6. API call → Database updated
7. Success message appears
8. QR ticket generated automatically
9. Can view ticket in "My Tickets"
10. Can download as image or share

ORGANIZER MARKS ATTENDANCE:
1. Opens app → Organizer dashboard
2. Clicks "Scan QR Code"
3. Camera opens with scanning frame
4. Student shows QR ticket
5. QR code scanned → Decoded
6. API call validates registration
7. Attendance marked in database
8. Success message with student details
9. Count updates (23/50 attended)
10. Can scan next student

HOD APPROVES EVENT:
1. Opens app → HOD dashboard
2. Sees pending approvals (3)
3. Clicks on "Tech Workshop 2026"
4. Reviews event details
5. Adds remarks (optional)
6. Clicks "Approve"
7. API call → Status updated
8. Forwarded to Principal
9. Organizer notified
10. Stats updated
