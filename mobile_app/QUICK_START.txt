┌──────────────────────────────────────────────────────────────────────────────┐
│ ⚡ FASTEST WAY TO RUN (2 minutes)                                            │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Open terminal/command prompt
  
  2. Navigate to project:
     cd campus-connect-mobile/mobile_app
  
  3. Install dependencies:
     flutter pub get
  
  4. Enable web:
     flutter config --enable-web
  
  5. Run in Chrome:
     flutter run -d chrome
  
  ✨ App will open in browser! Login with: student@example.com / password123

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔗 CONFIGURE BACKEND URL                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

  Edit: mobile_app/lib/config/api_config.dart
  
  Change line:
    static const String baseUrl = 'http://localhost:5000';
  
  To:
    For Android Emulator:   'http://10.0.2.2:5000'
    For iOS Simulator:      'http://localhost:5000'
    For Physical Device:    'http://YOUR_COMPUTER_IP:5000'
    For Production:         'https://your-domain.com'
  
  Find your IP:
    Windows: ipconfig
    Mac/Linux: ifconfig or ip addr

┌──────────────────────────────────────────────────────────────────────────────┐
│ ❓ TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  Problem: "Flutter not found"
  Solution: Install Flutter from https://flutter.dev
  
  Problem: "No devices found"
  Solution: flutter config --enable-web (for Chrome)
            Start Android emulator or iOS simulator
  
  Problem: "Cannot connect to backend"
  Solution: 1. Check backend is running: curl http://localhost:5000
            2. Update API URL in lib/config/api_config.dart
            3. For emulator: use 10.0.2.2:5000 instead of localhost
  
  Problem: "Gradle build failed"
  Solution: cd android && ./gradlew clean
            cd .. && flutter clean && flutter pub get
  
  Problem: "Hot reload not working"
  Solution: Press 'R' (capital R) for hot restart
