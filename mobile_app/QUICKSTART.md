# Campus Connect Mobile App - Quick Start Guide

## Getting Started

### Installation

1. **Download the App**
   - Download the APK file (Android) or install from App Store (iOS)
   - Install the app on your device

2. **First Launch**
   - Open the Campus Connect app
   - The splash screen will appear briefly

### Login

1. **Enter Credentials**
   - Email: Your registered email address
   - Password: Your account password
   - Check "Remember Me" to stay logged in

2. **Demo Accounts** (for testing)
   - Student: `student@example.com` / `password123`
   - Organizer: `organizer@example.com` / `password123`
   - HOD: `hod@example.com` / `password123`
   - Principal: `principal@example.com` / `password123`
   - Admin: `admin@example.com` / `password123`

## Features by Role

### Student Features

#### Browse Events
1. Tap "Browse Events" on the dashboard
2. View all upcoming approved events
3. Tap on any event to see details

#### Register for Events
1. Find an event you want to attend
2. Tap "Register Now"
3. Your QR ticket will be generated automatically

#### View Your QR Ticket
1. Go to "My Tickets"
2. View all your registrations
3. Show the QR code at the event for attendance

#### View Certificates
1. Tap "Certificates" on the dashboard
2. View all earned certificates
3. Download certificates as PDF

#### Submit Feedback
1. After attending an event
2. Navigate to the event
3. Rate the event (1-5 stars)
4. Add comments (optional)
5. Submit feedback

### Organizer Features

#### Create Event
1. Tap "Create Event"
2. Fill in event details:
   - Title
   - Description
   - Date and time
   - Mode (Online/Offline)
   - Venue (for offline events)
   - Meeting URL (for online events)
   - Department
3. Submit for approval

#### Scan QR Codes
1. Go to your event
2. Tap "Scan QR"
3. Point camera at student's QR code
4. Attendance is marked automatically

#### View Registered Students
1. Select your event
2. View list of registered students
3. Check attendance status

### HOD Features

#### Review Event Requests
1. View pending event requests for your department
2. Read event details
3. Approve or reject with remarks

### Principal Features

#### Final Event Approval
1. View events pending final approval
2. Review event details and HOD remarks
3. Give final approval or rejection

### Admin Features

#### System Overview
1. View total events, students, organizers
2. Check pending approvals
3. Monitor system activity

#### View Reports
1. Access analytics dashboard
2. View participation statistics
3. Export reports

#### Review Feedback
1. View all event feedback
2. Check ratings and comments
3. Analyze event performance

## Common Tasks

### Change Password
1. Tap profile icon
2. Select "Change Password"
3. Enter old password
4. Enter new password (min. 8 characters)
5. Confirm new password
6. Save changes

### Logout
1. Tap the logout icon in the app bar
2. Confirm logout
3. You'll be returned to the login screen

### Refresh Data
1. Pull down on any list to refresh
2. Data will be updated from the server

## Tips and Best Practices

### For Students
- Register early for popular events
- Save your QR ticket before the event
- Ensure good lighting when showing QR code
- Submit feedback to help improve events
- Download certificates promptly

### For Organizers
- Create events well in advance
- Provide clear event descriptions
- Test QR scanner before the event
- Mark attendance during the event
- Follow up on pending approvals

### For HOD/Principal
- Review event requests promptly
- Provide constructive remarks
- Check for venue/date conflicts
- Monitor department event calendar

### For Admins
- Regularly check system reports
- Monitor feedback for issues
- Review pending approvals
- Manage user accounts as needed

## Troubleshooting

### Cannot Login
- Check your email and password
- Ensure you have internet connection
- Contact admin if account is locked

### QR Code Not Scanning
- Ensure camera permission is granted
- Use good lighting
- Hold phone steady
- Clean camera lens

### Certificate Not Downloading
- Check storage permission
- Ensure internet connection
- Try again later if server is busy

### Events Not Loading
- Check internet connection
- Pull down to refresh
- Restart the app if needed

### Registration Failed
- Event may be full
- Check if already registered
- Verify event is still open

## App Permissions

The app requires these permissions:

- **Camera**: For QR code scanning
- **Internet**: To connect to backend
- **Storage**: To save certificates (Android)

You can manage permissions in your device settings.

## System Requirements

### Android
- Android 5.0 (API 21) or higher
- 50 MB free space
- Camera (for QR scanning)
- Internet connection

### iOS
- iOS 11.0 or higher
- 50 MB free space
- Camera (for QR scanning)
- Internet connection

## Privacy and Security

- QR codes are unique and cannot be duplicated
- All data transfer is secure
